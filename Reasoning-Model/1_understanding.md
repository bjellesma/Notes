# Intro

Reasoning models are needed when your task involves complexity like math and involves more compute. Don't confuse this with extended thinking. Most modern models like sonnet 4.5 are reasoning models which you can see by the fact that it uses chain of thought before it comes up with an answer. When you turn on extended thinking, you're just telling the model to use more tokens in chain of thought before it responds. You would want to do this if you have a complex reasoning problem like math.
